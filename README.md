MoodSound - Música para cada emoción

MoodSound es una aplicación móvil creada con Flutter que ayuda a los usuarios a encontrar música según su estado de ánimo. La aplicación busca brindar una experiencia personalizada, permitiendo descubrir canciones que se adapten a diferentes emociones y momentos del día.

Su diseño está enfocado en la simplicidad, facilidad de uso y una experiencia visual atractiva, permitiendo que cualquier usuario pueda navegar por la aplicación y reproducir música de manera rápida y cómoda.

Funcionalidades

Creación de cuentas de usuario. Acceso mediante inicio de sesión. Selección de emociones o estados de ánimo. Reproducción de música en streaming. Gestión de canciones favoritas. Navegación intuitiva entre pantallas. Almacenamiento local de información básica. Diseño moderno inspirado en aplicaciones musicales actuales.

Requisitos

Antes de ejecutar el proyecto es necesario contar con:

Flutter SDK instalado. Dart SDK. Visual Studio Code o Android Studio. Dispositivo físico o emulador Android. Instalación y ejecución Descargar el proyecto https://github.com/abi-jr/Moodsound_CAAL_ESMB/blob/main/README.md Acceder al directorio cd MoodSound Obtener dependencias flutter pub get Iniciar la aplicación flutter run

Guía rápida de uso Registrarse en la aplicación. Iniciar sesión con la cuenta creada. Elegir un estado de ánimo. Explorar las recomendaciones musicales. Reproducir canciones disponibles. Guardar canciones favoritas. Consultar la sección de favoritos. Personalizar algunas opciones de la aplicación.
